# Judgment Infrastructure skills

These four standalone skills live together here for easy browsing. Use any one on
its own, or combine them when the work calls for it. AI Project Steward remains
separate.

| Skill folder | Purpose | Source release |
| --- | --- | --- |
| [The Briefing Room](briefing-room/) | Organize messy context into a brief. | [v1.2.1](https://github.com/glichtenthal/briefing-room/releases/tag/v1.2.1) |
| [Ground Truth](ground-truth/) | Pressure-test ideas and plans with calibrated honesty. | [v1.2](https://github.com/glichtenthal/ground-truth/releases/tag/v1.2) |
| [The Quorum](the-quorum/) | Deliberate consequential decisions through multiple lenses. | [v1.4.1](https://github.com/glichtenthal/the-quorum/releases/tag/v1.4.1) |
| [Test Drive](test-drive/) | Design the smallest credible test before committing. | [v1.6.1](https://github.com/glichtenthal/test-drive/releases/tag/v1.6.1) |

Each folder contains the corresponding published `.skill` release, including
`SKILL.md`, references, and license. These are snapshots, not automatically
synced sources. The individual repositories and releases remain authoritative.
Three README release links have been changed to point to their original
repositories from this location; the skill instructions are unchanged.

For Codex, the [suite installer](../README.md#install-the-four-core-skills-for-codex)
can install all four or an individual skill. For other supported products, use
the installation instructions in the individual source repositories.
