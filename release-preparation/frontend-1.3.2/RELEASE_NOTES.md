## Changes

- Adds conditional runtime guidance for client/service contracts, stale responses, draft preservation, uncertain outcomes, safe retries, revision-bound approval, untrusted rendering and proportionate performance checks.

## Validation and limits

Bounded Codex evidence covers targeted approval/handoff cases, paired asynchronous repairs, a human-assisted corrected fictional composition, exact-package verification and one fresh native desktop bare-name loading check. Both the prior stable and candidate passed paired recovery; no general superiority is claimed. This is not certification of universal routing, Claude/ChatGPT compatibility, real providers, comprehensive accessibility/security, cross-browser performance, aesthetics or hands-off production readiness. See the tagged source's `release-preparation/frontend-1.3.2/EVIDENCE.md` for the bounded findings.
