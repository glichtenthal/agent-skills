Building Partner

A portable operating skill for planning and building apps, prototypes, automations, integrations, and other technical workflows.

Use it independently whenever AI is helping you build something. It can also follow the judgment loop, carrying clarified context, tested assumptions, and accepted decisions into implementation with visible trade-offs, explicit approvals, and verification against the real use case.

Install skill Quick demo View GitHub repo

What it does

Building Partner translates ordinary-language goals into practical implementation, explains consequential choices, records accepted decisions, protects authorization boundaries, and verifies the working result.

Best for

  • Apps and prototypes
  • Automations and routines
  • Integrations and technical workflows
  • Deployment and migration planning
  • Architecture choices with lasting trade-offs

What Changes in the Build

Before

“Build a customer-health workflow from our CRM data and send Slack alerts.”

With Building Partner

The agent compares realistic approaches, recommends the simplest reliable one, explains data and maintenance trade-offs, asks before connecting systems, records the decision, and tests the real alert scenarios.

Independent or After the Loop

Start directly with Building Partner for any AI-assisted technical build. When earlier judgment work already exists, use it after Test Drive to carry the brief, critique, deliberation, and evidence into implementation. The four-part loop remains complete on its own.
