When a build needs all three

For a new product interface, Steward keeps scope, decisions, and approval boundaries clear throughout the work. Director defines the experience and design, then Engineer implements it and checks the behavior. Director critiques the rendered result, and Steward checks completion against the agreed goal.

Design and engineering can go back and forth as the work develops. A narrow frontend fix can stay with Engineer; a design review can stay with Director. One agent can apply multiple skills, or separate agents can take the roles when your setup supports it.

Example: a notification settings page

Steward surfaces decisions about delivery services, data, and approval to send. Director defines the controls, defaults, and feedback. Engineer builds and checks the interface, including saving and error states. Use the roles that address what is still unresolved.

Install the skills you need

Each skill is available separately. For Claude, upload and enable the individual skill ZIPs you want to use. For Codex, install the corresponding skill folders. Installing all three makes the combined workflow available; it does not create three separate agents.

The installation guide includes release downloads, platform instructions, and the limits of the recorded evaluations.
