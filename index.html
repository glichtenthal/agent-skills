Frequently Asked Questions

What is judgment infrastructure for human-led AI?

It is a set of portable AI skills that help people structure messy information, challenge their own reasoning, and make better decisions without outsourcing human judgment.

What is an agent skill?

An agent skill is a portable set of instructions, examples, and metadata that helps an AI agent perform a specialized workflow more reliably than a one-off prompt.

What is evidence design?

Evidence design means identifying what kind of signal would make an idea more or less trustworthy, then creating the smallest useful test to gather that signal.

When should I use The Briefing Room, Ground Truth, The Quorum, or Test Drive?

Use The Briefing Room when the context is messy, Ground Truth when you want honest critique on a plan or claim, The Quorum when you need multiple expert lenses on a consequential decision, and Test Drive when you need evidence before committing.

How do I install these skills in Codex or Claude?

Each portable skill has a GitHub repository, a release download, and installation instructions. The four core judgment skills install as a suite. AI Project Steward installs separately and is recommended for people who regularly build apps, prototypes, automations, integrations, or deployments with AI.
